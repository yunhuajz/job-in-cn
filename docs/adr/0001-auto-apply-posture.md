# 自动化投递档位:批量批准后自动投(A2),HR 确认只随招呼语、回复只读(B)

**Status**: accepted(2026-07-22)

Boss 直聘的自动化定为两档:**投递走 A2** —— 用户在看板批量圈选批准后,bot 按人化节奏自动逐个投出;**双休/节假日/薪资确认走 B** —— 不单独开聊天,而是把确认问句塞进投递时必发的招呼语里(JD 已写明的不问),HR 回复只读捕获并回填字段。永不做全自动投递(A3)与自主 HR 对话(B2/B3)。

## 背景与权衡

三个参考仓库(ai-job-search / career-ops / jobsync)都明确「不替用户点投递」,本决策是有意反转这一原则,换取自动化;但保留「人决定投给谁」这道闸,避免海投与机器人行为特征。HR 对话自动化的封号风险与欺骗成本(对面是真人)过高,因此只起草、只读收,不自主对话。

## 被拒绝的替代方案

- **A3 全自动**(bot 自行发现→评估→投):Boss 行为风控下近似封号直通车。
- **B2/B3 自动发 HR 消息/自主谈判**:聊天是 Boss 反作弊重灾区,且让 bot 冒充用户与真人对话有欺骗性质。
