# 0002. 使用 REST API 取代 MCP 作为外部岗位录入接口

JBCN 的实际外部集成只需要让 AI 工具或普通脚本提交结构化岗位。投递必须由用户在页面复核并确认，因此 MCP 的工具发现和多工具编排没有带来实际收益，却引入了独立协议路由、工具注册、模型、鉴权和测试维护成本。

我们删除对外 MCP 服务，保留标准的 `POST /api/local/jobs`。外部调用使用 Bearer Token，令牌只授予 `jobs:write` 权限，并映射到所属用户。浏览器内调用仍可使用登录会话。所有录入统一进入 `ingestJob`；任何投递动作都不向 API Token 开放。

原有令牌数据通过数据库迁移重命名为通用 API 访问令牌，避免用户升级后丢失已经创建的凭据。
