# Boss 直聘自动化:读侧陪同式抽取(人开车、机器读书)、写侧浏览器扩展驱动、人化频率、验证码交人、熔断

**Status**: accepted(2026-07-22;2026-07-24 修订;2026-07-26 修订 ×2)

Boss provider 分两侧实现,统一走**用户日常真实浏览器 + OpenCLI Browser Bridge 扩展**这一通道。**读侧**(扫描 / JD 抽取 / 消息捕获):**陪同式抽取** —— 用户本人在真实浏览器里搜索、翻页、点详情(真人行为,零风控),系统经扩展**被动读取**当前页职位数据落库;不做无人值守扫描。**写侧**(发招呼语):用户晚间批量批准后,由 AI agent(Kimi Code / Claude Code)经同一扩展通道驱动真实浏览器,选中 Boss 预存的一版常用语一键发送 —— 用户全程在场,验证码/滑块交人,风控弹窗当天熔断停投。频率约束不变:每日 ≤20 条招呼、间隔随机 30s–3min、仅 9:00–21:00。登录态不再是问题:直接用用户日常浏览器(已登录)的会话,无专用 profile、无 QR 扫码环节。

## 背景与权衡

团队(用户与 AI agent)只掌握 Playwright,统一技术栈优先级高;慢是 feature —— 慢 = 像人 = 不封。单账号、用本人真实账号,不上小号矩阵。

**2026-07-24 修订说明**:写侧原定由 Playwright 脚本自动发送,改为 AI agent + chrome-devtools MCP 驱动,理由是 AI 能看着页面现场适配选择器、识别验证码与风控弹窗。

**2026-07-26 修订说明**:对 Boss 反爬做了三通道实测,**所有「程序主动驱动浏览器」的通道全部被识别**:

| 通道 | 实测结果 |
|---|---|
| Playwright `launchPersistentContext`(真 Chrome 150 与内置 Chromium 均试) | 页面加载后被踢到 `about:blank`(`navigator.webdriver` 可检测到;即使置 false 仍被更深检测踢出) |
| chrome-devtools MCP(CDP 驱动) | 同样被踢到 `about:blank` |
| OpenCLI 扩展**主动导航** | 页面被干扰,持续刷新 |
| OpenCLI 扩展**被动读取**(eval 读当前页 DOM) | **存活**,拿到完整页面数据;且真实浏览器天然是登录态 |

结论:与 Boss 风控硬对抗(stealth 插件等)是猫鼠游戏,对方升级即失效,维护成本无底;而「用户自己浏览 + 系统被动读取」零对抗、零风控特征。故读侧放弃无人值守扫描,改为陪同式抽取;写侧通道随之统一到浏览器扩展(CDP 通道已证伪)。代价:「白天定时自动扫描」不可行,扫描量取决于用户的浏览行为 —— 用户接受这一降级,因为扫描环节本来就需要人最终过目。

**2026-07-26 修订说明(第二次)**:发现 OpenCLI 自带 `boss` 站点适配器(`opencli boss search/detail/chatlist/whoami` 等),经同一 Browser Bridge 扩展复用日常 Chrome 登录态,**主动打开标签页采集并直接返回结构化 JSON,实测存活**:whoami(geek 登录态确认)、search(15 条推荐)、detail(JD 全文/福利/公司信息)、chatlist(消息列表只读)全部成功。此前「OpenCLI 主动导航被干扰」的结论只适用于 `browser open` 粗暴导航 Boss 页面 UI;适配器走的是页面内 API 路径,行为面不同。经用户明确批准(「铁律可以改,可以主动导航」),读侧从「陪同式被动抽取」升级为「适配器主动采集」:`npm run boss:harvest` 按画像「关键词 × 城市」轮询,jobId(URL)去重落 jobsync,dry-run 已验收(新入库 2 / 去重跳过 1 / 异常 0)。DOM 解析器随之不再需要(适配器直接给结构化数据)。已知运维点:扩展标签页租约间歇过期(stale page identity),`src/boss/bridge.ts` 自动重建标签页重试一次;单次调用 90s 硬超时防挂死;jobsync MCP 传输层在客户端被杀时会整体卡住,需重启 dev server(2026-07-26 实测一次)。

## 被拒绝的替代方案

- **逆向 Boss 内部 API**:请求带设备签名/加密,逆向难且官方一改即失效,风控对纯 API 调用最敏感,封号最快。
- **桌面客户端 UI 自动化(pyautogui/UIA)**:仅 Windows、需前台 GUI 会话、按坐标点易崩、读不到结构化数据、原生文件对话框难传简历、无法容器化。
- **写侧由 daemon 脚本自动发送**(原方案,2026-07-24 废弃):选择器脆弱、无法识别验证码与风控弹窗。
- **读侧 daemon 无人值守 Playwright 扫描**(原方案,2026-07-26 废弃):被 Boss 风控踢到 `about:blank`,见上表。
- **客户端 CDP 挂接(connectOverCDP)**(原备案,2026-07-26 证伪):CDP 通道同被识别,同见上表。
- **stealth 插件硬对抗**(2026-07-26 拒绝):猫鼠游戏,Boss 升级即破,长期维护成本不可控。
- **确认问句塞进招呼语**(ADR-0001 已废弃,此处不重复)。
