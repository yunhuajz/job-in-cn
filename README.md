# job-in-cn (JBCN) 🇨🇳

> **专为国内求职者打造的个人 AI 智能求职工作台。**  
> 一站式打通 **Boss直聘、前程无忧 (51job)、智联招聘** 三大主流平台：安全采集、集中去重、大模型深度匹配评分、本地看板追踪。

---

## 💡 这个项目是干嘛的？

如果你正在国内找工作（尤其是技术、产品、运营等岗位），你一定经历过这些痛点：

1. **多平台来回切换太累**：每天要在 Boss直聘、前程无忧、智联招聘之间反复切换、重复搜索，信息碎片化严重。
2. **垃圾岗位多、有效信息少**：大量 JD 写的模棱两可，工资虚高、不写是否双休、学历/年限要求暗藏玄机，纯靠人工肉眼一条条甄别极度耗费精力。
3. **市面上的自动化脚本动辄被封号**：很多爬虫或自动投递插件使用强行驱动浏览器的方式（如无头浏览器自动化），几分钟就会触发平台风控、弹出滑块甚至封禁账号。
4. **隐私泄露担忧**：很多求职 SaaS 工具要求你把简历和求职记录上传到他们服务器，存在个人隐私和联系方式被倒卖的风险。

---

### 🎯 JBCN 是如何解决这些问题的？

**JBCN (Job in CN)** 就像一个住在你电脑里的 **“AI 求职专属秘书”**：

```
      【三大招聘平台】
(Boss直聘 / 前程无忧 / 智联)
          │
          │ 1. 真实浏览器安全读取 (被动抽取 + 防风控降速)
          ▼
   ┌──────────────┐
   │  JBCN 数据引擎 │ ──► 自动清洗、跨平台去重、结构化提取
   └──────┬───────┘
          │
          ├───────────────────────────────┐
          ▼ 2. 本地 AI 智能打分             ▼ 3. 本地可视化看板
   ┌──────────────┐               ┌──────────────┐
   │   大模型     │               │  Web 界面     │
   │ (DeepSeek /  │ ◄── 结合个人 ──│ (Next.js 本地)│
   │ Claude / GPT)│     真实简历   │ (127.0.0.1)  │
   └──────┬───────┘               └──────┬───────┘
          │ 给出匹配度、理由与建议           │
          └───────────────────────────────┘
                          │ 4. 投递安全闸
                          ▼
            【由你确认后，一键安全投递】
```

1. **安全第一的“陪同式采集”**：
   - 你在自己的日常 Chrome 浏览器中登录招聘网站（你过验证码，保持真实登录态）。
   - JBCN 通过浏览器扩展通道被动提取页面数据，支持三大平台多轮轮转采集、自动等待冷却、风控检测与暂停，**绝不做高危自动化对抗，保障账号安全**。
2. **多平台岗位汇聚与去重**：
   - 无论从哪个网站抓到的岗位，统统汇入你电脑本地的 SQLite 数据库，告别多平台来回切换。
3. **让 AI 大模型拿着你的简历去读 JD（逐条打分）**：
   - 把你的真实简历（PDF / Word）交给系统，配置你喜欢的大模型（支持 **DeepSeek、ChatGPT、Claude、Kimi、Ollama 本地模型** 等任何 OpenAI 兼容协议）。
   - AI 会根据你的技能匹配度、项目经验契合度对岗位逐一打分（1~5 分），并写出分析报告，让你只把时间花在最合适的高分岗位上。
4. **全生命周期求职看板**：
   - 在本地网页上，像管理任务一样管理所有岗位状态：`未投递` ➔ `投递过` ➔ `深度推进中` ➔ `收到 Offer`。
   - 支持按关键词、城市、学历（如应届生/本科筛选）、薪资上限/下限、经验年限、是否双休一键过滤。
5. **严格的“人闸”投递机制 (Human-in-the-loop)**：
   - **绝不盲目海投！** 系统会准备好打招呼清单，最终投递按钮必须由你亲自点击确认才会发出。
6. **100% 本地隐私安全**：
   - 简历、求职进度、沟通记录、API Key 全部保存在本地数据库中，**零云端中转，零数据回传**。

## 🚀 5 分钟上手指南

### 1. 环境准备
- 操作系统：Windows / macOS / Linux
- **Node.js** >= 22.0.0
- **Google Chrome 浏览器**（日常正常使用，并已登录 Boss直聘/前程无忧/智联等账号）
- 安装并启动 **OpenCLI Browser Bridge** 扩展（用于安全读取浏览器标签页内容）

### 2. 克隆与安装依赖
```bash
# 1. 克隆代码
git clone https://github.com/yunhuajz/job-in-cn.git
cd job-in-cn

# 2. 安装根目录依赖
npm install

# 3. 安装 Web 端依赖
cd apps/web
npm install
cd ../..
```

### 3. 初始化与启动服务
在项目根目录下，直接执行：
```bash
# 方式 A：使用内置启动命令（Windows 推荐）
.\JBCN.cmd

# 方式 B：使用 npm 启动
npm run dev
```
启动成功后，浏览器会自动打开或手动访问：
👉 **`http://127.0.0.1:3737`**

首次启动会自动初始化本地 SQLite 数据库（存放在 `apps/web/prisma/dev.db`），无需繁琐的账号注册配置。

## ⚙️ 典型使用流程

```
第 1 步：【AI 设置】填入你的 API Key（例如 DeepSeek 或 OpenAI）并测试连通性。
第 2 步：【简历管理】上传你的 PDF / Word 简历，设为默认评分参考。
第 3 步：【爬虫控制】输入目标职位关键词（如“前端开发”）、城市（如“北京”），启动采集。
第 4 步：【岗位看板】查看采集回来的岗位，勾选感兴趣的岗位点击“批量评分”。
第 5 步：【决策投递】根据 AI 得分与分析，对满意的高分岗位执行确认投递，追踪求职进度。
```

## ❓ 常见问题 (FAQ)

<details>
<summary><b>Q: 为什么不采用完全无人的“后台静默抓取”？</b></summary>
国内主流招聘网站（特别是 Boss 直聘）拥有行业最严苛的反爬风控策略。所有使用无头浏览器（Headless Chrome / Playwright 自动驱动）的方法均能在短时间内被识别并阻断。JBCN 创新性地采用“人在浏览器正常浏览，工具在后台被动读取”的陪同式设计，以零对抗换取零封号风险。
</details>

<details>
<summary><b>Q: 支持哪些 AI 大模型？</b></summary>
任何兼容 <b>OpenAI 规范</b> 或 <b>Anthropic 规范</b> 的大模型均可直接使用！包括：
- 国内高性价比模型：DeepSeek (V3 / R1)、Moonshot (Kimi)、智谱 GLM、Qwen 通义千问等
- 国际顶尖模型：Claude 3.5 Sonnet、GPT-4o 等
- 本地离线模型：通过 Ollama / LocalAI 部署的本地私有模型（完全免费且不花一分钱 Token）
</details>

<details>
<summary><b>Q: 我的个人简历和数据安全吗？</b></summary>
<b>绝对安全。</b> 本项目专为个人自托管设计，没有任何云端数据收集机制。所有职位缓存、个人简历、打分记录、API 密钥均加密存储在你的本地磁盘中。
</details>
