---
description: 对话式填写候选人画像(profile/candidate.yaml)并验证
---

引导用户填写候选人画像。逐字段询问,每个字段先说明用途与格式,拿到答案再继续;不要从简历或对话历史猜测(见 docs/plan.md 1.1)。字段定义与注释风格照 `profile/candidate.example.yaml`,术语见 `CONTEXT.md`:

1. **targetRoles**(字符串数组):目标岗位关键词,扫描时与城市做「关键词 × 城市」组合轮询。问:「想投哪些岗位?给几个搜索关键词。」
2. **preferredCities**(字符串数组):期望工作城市。问:「期望哪些城市?可含『远程』。」
3. **salaryFloor**(字符串):Boss 薪资过滤器下限档位,形如 `"20K"`。问:「期望月薪下限多少?」
4. **experience**(字符串):Boss 经验过滤器档位,合法值:在校生 / 应届毕业生 / 1年以内 / 1-3年 / 3-5年 / 5-10年 / 10年以上。问:「你的工作年限?」并映射到合法档位。
5. **skills**(字符串数组):技能清单,与 JD 比对产出技能匹配分。问:「列一下你的核心技能。」
6. **avoidKeywords**(字符串数组):公司质量惩罚词,JD 或公司名命中扣分。问:「哪些词出现的公司你不想投?(如外包、996、大小周)」

scoring 段不需要问,照 example 原样复制。

收齐后:
1. 把答案按 example 的结构与注释风格写入 `profile/candidate.yaml`(该文件已被 gitignore,不进库)。
2. 运行 `npm run profile:check` 验证;失败则按报错修正后重跑,直到通过。
3. 向用户复述最终画像要点,确认后结束。
